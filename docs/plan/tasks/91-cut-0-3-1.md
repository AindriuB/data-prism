## Goal

Cut 0.3.1 so that the MCP Registry entry can be refreshed. Registry versions are
immutable, and the live v0.3.0 entry still carries the old description ("Privacy
layer for enterprise APIs; refuses to start without a reviewed adapter jar per
source") and has no `websiteUrl`. The release also ships everything merged to
main since v0.3.0. Owner decision (2026-09-24): 0.3.1 goes to **GHCR and the MCP
Registry only**. Maven Central stays at 0.3.0, so any coordinate a reader would
copy into their own build must keep saying 0.3.0.

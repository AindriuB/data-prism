   boundary. In production, isolate 5701 with a host firewall, a NetworkPolicy or a private network.
   Remove "cannot reach it".
2. **multiple-instances.md.** Make the same correction wherever isolation is claimed for the Compose example.
3. **compose.build.yaml.** Give `server-b` the same `build:` block as `server-a`, so that a clean machine never

   "Using the starter". The CHANGELOG may link to them.
5. **CHANGELOG [0.4.1].** Add the Publication section (Central library modules, not
   `data-prism-server`; GHCR; MCP Registry), and a Known-limitations line on the Compose isolation finding.
6. **Re-check.** Run `docker compose config -q` for both files, mkdocs strict, check_site, check_changelog and

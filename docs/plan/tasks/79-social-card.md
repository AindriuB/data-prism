## Goal

A 1280×640 PNG with tagline T on it, used as the site's `og:image` and
Twitter card (task 82) and as the repo's social preview (an owner upload).
It is generated by a script with a pinned Pillow version, so anyone can
regenerate it and get the same file.

## Context

- `docs/plan/specs/2026-09-23-discoverability.md` — binding. Read "T4" and
  "Canonical description".
- **Tagline T**, verbatim:
  `Fail-closed privacy layer that pseudonymises enterprise API data for LLM agents and MCP clients.`
- The output path is fixed, because task 82's overrides reference it:
  `docs/assets/social-card.png`.
- Fonts: Pillow 10.1 and later can render a bundled scalable default font
  (`ImageFont.load_default(size=…)`), which avoids committing a font file. If
  you commit a font instead, it must be OFL or Apache licensed, and its
  licence file goes next to it under `docs-site/social-card/`.
- `docs/assets/` will be published by the site. Put nothing there except the
  card.
- `docs-site/` is shared with task 82 (`requirements.txt`, `hooks/`,
  `overrides/`, `page-meta.yml`). This task owns only
  `docs-site/social-card/`.

## Acceptance

- [ ] `docs-site/social-card/requirements.txt` pins Pillow with `==`.
- [ ] `docs-site/social-card/make_card.py` (or a similarly named script)
      writes `docs/assets/social-card.png`.
- [ ] `docs-site/social-card/README.md` gives the regenerate command.
- [ ] `python3 -c "from PIL import Image; im=Image.open('docs/assets/social-card.png'); print(im.size, im.format)"`
      prints `(1280, 640) PNG`.
- [ ] `stat -c %s docs/assets/social-card.png` is under 1,000,000.
- [ ] Regenerating in a fresh venv from the pinned requirements produces a
      byte-identical file (`cmp` exits 0 against the committed PNG).
- [ ] T appears verbatim as one string literal in the script
      (`grep -F "$T" docs-site/social-card/*.py`). The reviewer views the PNG
      and confirms that T is fully visible and legible at 1280×640 and when
      scaled down to 600×300. T may wrap across lines, but no word may be cut
      off.
- [ ] The card contains no other claim text. "Data Prism" and the repo URL
      or site URL are allowed.
- [ ] If a font file is committed, its licence file sits beside it.
- [ ] `git diff --name-only discoverability` lists only files under the two
      owned paths.
